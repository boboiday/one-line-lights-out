A single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop. The sadness lives in small specifics — a cursor still blinking on "see you tomorrow", a playlist paused mid-chorus, a tab that still says "waiting for you" — not in announced grief.

## Run it

```sh
node main.ts
```
